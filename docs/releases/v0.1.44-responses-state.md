# v0.1.44 Responses 状态与重试修复

日期：2026-10-23。分支：`main`。上一发布版本：`v0.1.43`。

## 修改内容

- 状态绑定渠道返回 HTTP/SSE 429 且尚未输出时，按上游等待提示或指数退避在原渠道、原 Key 重试；单次要求等待超过 30 秒时明确停止。保持请求正文、重试次数和资源边界。
- Responses 流等待响应头、前置事件及输出阶段传播客户端取消；未完成流按 `client_cancelled` / 499 归因，避免误记上游故障、向断开连接写失败事件或误禁用渠道。
- 渠道从空值补填 Provider 后，新旧历史混用或显式指定 Provider 时，核对原渠道当前 Provider 和原 Key 指纹后允许续接。仍固定原渠道/Key，不改写状态索引；缺少指纹、Key 更换、渠道不可用或 Provider 冲突时拒绝。
- 同步 [Provider 使用说明](../channel-provider.md)、[变更记录](../CHANGELOG.md) 和[实施计划](../plans/2026-10-22-responses-prelude-retry.md)。

本次包含 `8213df6`（v0.1.43 复审文档）、`b13f871`（状态绑定重试与取消归因）及 Provider 补填兼容修复 `ff69577`。无数据库迁移。
