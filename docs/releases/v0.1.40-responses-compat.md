# v0.1.40：Responses 错误兼容与交接

## 本次解决的问题

Responses 流中断时，以前裸 `error` 或直接 EOF 会让 Codex 只显示 `stream closed before response.completed` 并反复重连。现在流开始后的失败以带嵌套 `response.error` 的 `response.failed` 结束。上游已有失败事件时，数字错误码、空/null/缺失错误及空白字段先规范化，避免客户端解析失败；只发送一个终止失败事件。

合法事件保持原样，修正事件保留序号、response id、响应元数据和扩展字段，大整数不丢精度。缓存故障仍不透出未成功绑定的 response id。Responses 的渠道错误处理收回请求生命周期内，修复完整路由 race 检查发现的后台配置读取竞态。
