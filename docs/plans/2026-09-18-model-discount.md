# 模型折扣

## 目标
价格配置增加模型折扣，默认 1.0；保留原价，计费乘以模型折扣，公开价格展示删除线原价、折后价和 OFF 比例。

## 方案
- 使用现有 Option 存储 ModelDiscount，不改变数据库结构；数值范围 (0, 1]，省略字段保留配置，1 取消优惠。
- 单个和批量价格接口校验并保存折扣；公开列表和详情返回折扣及折后价格。
- 同步、异步计费接入模型折扣，沿用各入口原有计费模型名和取整方式。
- 修改相邻 linkinfra-web 仓库的价格配置列、公开价格卡片及详情。

## 验证
覆盖默认值、非法配置、保存、批量更新、折扣叠加和原价不变；运行 Go 测试、编译、静态检查及前端类型检查、构建。
