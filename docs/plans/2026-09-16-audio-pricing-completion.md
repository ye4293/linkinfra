# 音频按时长计费补齐与发布

## 背景与目标

后端已有 f210bec 的时长计费实现，实际前端 linkinfra-web 尚未发布管理入口、分钟价格展示与时长日志。本轮补齐前后端后再分别推送 main。

## 方案设计

- 后端合并本地 `model/audio-pricing.go`、`model/option.go`、`controller/pricing.go` 与接口测试：按模型合并分钟价格，先校验再保存，数据库失败不更新运行价格。
- 前端发布分钟价格管理，补齐目录类型与校验、模型卡片/表格/详情的美元/分钟展示，以及消费日志的秒数和公式。
- 修正旧计费文档的前端路径和保存 API，记录零价格、删除价格及缺失时长的行为。

## 影响范围

沿用现有 Option 数据结构，不迁移数据库；不修改 TTS、Realtime 或普通 Token 模型的计费路径。新前端需要先部署支持模型级分钟价格更新的后端。

## 验证方式

后端运行音频配置、余额与转录回归，以及 `go build ./...`、`go vet ./...`；前端运行目录/计费展示回归、类型检查和生产构建，模拟接口检查单个/批量设置、0 元、删除和失败状态。真实上游计费不以模拟结果替代。
